# 공용어와 생활 언어

## 세력별 공용어
| 세력 | 공용어 |
|---|---|
| 소행성대 | 독일어 |
| 금성 | 영어 |
| 화성 | 중국어 |
| 아스테리아 | 영어 |

## 아스테리아의 다언어 생활
공적인 영역에서는 영어로 소통하지만 집집마다 생활 언어가 다르다. 같은 학교·직장에서 영어를 쓰는 사람들이 가정에서는 가족의 언어로 생활한다. 다국적 난민·이민자의 정착 역사가 이 언어 환경으로 이어진다.

공용어가 있다는 이유로 다른 언어의 가정 내 사용을 금지하거나 모든 세력의 생활 언어가 하나로 통일된 것으로 보지 않는다.

## 문화적 명칭과 언어 서비스
금성의 영어 공용어와 화위안 그룹·선씨 가문의 중국계 문화가 공존한다. 금성의 테라포밍 사업은 중국어식 명칭인 **환톈 계획(换天计划)**을 쓴다. 화성의 신규 주요 기업명은 영어식 브랜드를 사용한다.

현대적 AI가 없어 번역·다언어 서비스에는 인간 번역가와 운영 인력이 필요하다. [[02_세력/아스테리아의 주요 기업\|폴리폰 네트웍스]]가 이러한 수요를 기반으로 성장한다.
