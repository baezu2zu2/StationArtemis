# 금성 행정구역

금성은 **7개 행정구와 2개 직할구**로 구성된다. 각 구역은 여러 거주 시설·산업 거점을 묶는 행정 단위이며, 테라포밍된 지표의 연속된 토지를 나눈다는 뜻은 아니다.

## 행정구와 직할구
| 구역 | 주요 기능 | 주요 공간과 성격 |
|---|---|---|
| 화위안 특별행정구 | 중앙정부·그룹 본사·외교 | 회장 집무실·중앙 행정기관, 선씨 가문과 고위 경영진의 권력 집중 |
| 신상하이구 | 금융·상업·고급 주거 | 선씨 가문의 고향을 기리는 명칭. 금융회사·외국 기업 지사와 부유층 생활권 |
| 진차오구(金桥) | 국제항·세관·물류 | 외국 선원·상인·이주 노동자가 드나드는 대외 관문 |
| 톈궁구(天工) | 제조·조선·정비 | 에너지 수집 위성·산업 설비 생산, 기술자·생산 노동자 밀집 |
| 슈광구(曙光) | 연구·기술 개발 | 연구소와 기술 개발 시설 중심 |
| 쉐위안구(学苑) | 학교·대학·직업교육 | 학교·실습시설, 테라포밍 인력의 기술 교육·자격 취득과 채용의 연결 |
| 안쥐구(安居) | 일반 주거·생활 서비스 | 직원과 가족의 생활권, 회사 배정 주택·학교·의료시설 |
| 헬리오스 에너지 직할구 | 다이슨 스웜 운영·관제 | 금성 인근 운영 거점과 화위안 소유 원격 에너지 시설을 묶는 특별 관할 |
| 개척 직할구 | 금성 테라포밍과 종사자 거주 | 작업 거점·거주 시설·교대 및 수송 시설, 위험한 업무를 통한 신분 상승 기회 |

헬리오스 에너지 직할구의 원격 시설 관할은 태양 주변 공간 전체의 영유권을 뜻하지 않는다.

## 행정과 생활
각 지역의 **행정총감**은 회장이 임명하며 핵심 사업부의 경영 책임을 겸한다. 직원·주민협의회는 생활 문제를 건의하지만 총감 선출권을 갖지는 않는다.

직장 내 지위와 주거 환경이 연결된다. 승진은 상위 주거지 배정으로, 해고는 사택과 생활 혜택 상실로 이어질 수 있다. 기업에 생활 기반을 의존하는 구조는 아스테리아로의 이주 동기와도 연결된다.

## 개척 직할구
테라포밍에 힘쓰는 사람들과 가족이 주로 거주한다. 매우 위험하고 어려운 업무지만 그만큼 보상과 승진 기회가 커 **금성에서 가장 쉽게 신분을 상승시킬 수 있는 통로**다. 2541년에도 금성 테라포밍은 완료되지 않았다.

## 교육 지구
쉐위안구가 교육 지구다. 일반 교육과 직업교육을 제공하며 실습·자격 취득·채용을 연결한다. 개척 직할구로 향하는 기술 인력의 교육 기반이기도 하다.
