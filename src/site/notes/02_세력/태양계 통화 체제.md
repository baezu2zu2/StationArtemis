# 태양계 통화 체제

## 기본 구조
각 지역은 자체 통화를 사용하며, 태양계 기축통화는 [[02_세력/USS\|USS]]가 발행·관리하는 **솔**이다.

아스테리아는 발달한 금융업을 가진 영세중립국이자 USS 본부 소재지다. 금융 중심지와 통화 관리 주체는 구분한다.

## 통화명 — 확정
| 발행·관리 주체 | 통화명 | 약칭 | 명명 취지 |
|---|---|---|---|
| USS | 솔 / Sol | SOL | 특정 행성에 속하지 않는 태양계 공동체 |
| 아스테리아 | 아스터 / Aster | AST | 국호와 별의 이미지 |
| 화성 | 화성 마르크 / Mark | MMK | 산업·상업 전통 |
| 금성 | 금성 위안 / Yuan | VYU | 중국계 기업국가의 기원 |
| 소행성대 | 연합 탈러 / Thaler | BTL | 기업 영지들 사이 상업 통화 |

약칭은 세계관 내부의 표기다.

## 도입 시점
**2348년 USS 출범**, **2374년 아스테리아 공동결제소 설립**, **2398년 USS 공동통화 솔 도입** 순서다. 공동기구의 성립과 통화 도입은 50년 차이가 난다. [[01_역사/역사 연대기\|역사 연대기]] 참조.
