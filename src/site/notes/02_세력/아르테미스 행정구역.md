# 아르테미스 행정구역

> 거대한 달 궤도 정거장과 연결 모듈들이 하나의 도시국가를 이룬다. **8개 구역**과 주변 달 산업시설의 관할 관계를 구분한다.

| 구역 | 주요 기능 | 주요 장소·특성 |
|---|---|---|
| **센트럴구 (Central)** | 행정·의회·외교 | 의회광장, 정부청사, 외교가 |
| **게이트구 (Gate)** | 여객항·출입국 | 제1국제항, 신항, 환승 상업지 |
| **포지구 (Forge)** | 조선·제조 | 제1조선소, 신조선단지, 기술자 거주지 |
| **트랜짓구 (Transit)** | 화물·물류 | 중앙화물항, 우주물류거래소, 자유무역지대 |
| **헤이븐구 (Haven)** | 주거·상업 | 뉴헤이븐, 커먼스, 메인 스트리트 |
| **헤리티지구 (Heritage)** | 구도심·다문화 | 올드타운, 엑소더스 광장, 국제시장 |
| **아카데미구 (Academy)** | 대학·연구 | 국립대, 소영연구단지, 항행연구소 |
| **[[02_세력/바이스구\|바이스구]] (Weiss)** | 핵심 생명유지·환경 제어 | 옛 **바이탈구(Vital)**, 2391년 개칭 |

## 교통과 외곽 구역
- 내부 이동은 밀폐형 여객 교통과 자동 화물 운송망 중심. 화물과 일반 거주 동선을 분리.
- 달 표면 채굴·가공·발사 시설과 외곽 물류 정거장은 아르테미스의 산업 기반이다.
