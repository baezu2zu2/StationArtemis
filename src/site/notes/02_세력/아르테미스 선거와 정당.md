# 아스테리아 선거와 정당

## 선거 제도 — 확정
- **의원내각제**, 단원제 의회 **200석**.
- 의회 임기 **4년**, **정당명부 비례대표제**, 의석 배분 **4% 봉쇄조항**.
- 의회 과반(101석) 지지를 확보한 총리를 선출.
- **건설적 불신임제:** 기존 총리를 교체할 때 새 총리를 함께 선출해야 한다.
- 만 **18세 이상** 아스테리아 시민 선거권.
- 시민권은 혈통·출생 국가보다 소속과 귀화를 기준으로 하며 장기 거주자는 요건을 거쳐 취득 가능. 단기 체류자는 자동 선거권이 없다.

## 주요 5당 — 채택된 구도
| 정당 | 기본 성향 | 주요 의제 |
|---|---|---|
| **국민당** | 중도우파 | 시장경제·안정·시민 생활 |
| **사회민주당** | 중도좌파 | 복지·노동권·불평등 완화 |
| **시민당** | 중도 | 다문화 통합·시민권·행정 개혁 |
| **중립당** | 중도, 중립주의 | 외교 중립·외국의 정치적 개입 경계 |
| **개척당** | 개발주의 | 우주 개발·산업 확장 |

- 국민당과 사회민주당이 **양대 중심 정당**, 시민당·중립당·개척당은 **군소정당**.

- 이민에 관한 입장은 어느 정당에서도 완전히 단일하지 않다. [[02_세력/이민 정책 논쟁\|이민 정책 논쟁]] 참조.
