# 게임산업과 게임사

## 게임사 3개
| 게임사                                 | 소재지·지위       | 출발과 특징                                          | 대표작                               |
| ----------------------------------- | ------------ | ----------------------------------------------- | --------------------------------- |
| 스페어룸 게임즈 / Spare Room Games         | 아스테리아의 독립 기업 | 공동주택의 작은 방에서 창업. 저사양 단말의 협동·파티게임으로 성장           | 《교대 끝!》 — 가상의 작업장을 친구들과 수습하는 협동게임 |
| 블루 호라이즌 스튜디오 / Blue Horizon Studios | 화성의 독립 창업 기업 | 에디슨 계열이 아닌 게임 개발사의 성공 사례. 자연·탐험을 다루는 대작에 강점     | 《와일드 센추리》 — 광대한 자연 탐험             |
| 코메텐베르크 슈필레 / Kometenwerk Spiele     | 소행성대 준회원 기업  | 산업시설용 소프트웨어 개발자들이 여가에 만들던 게임에서 출발. 건설·경영 게임에 강점 | 《오비탈 파운드리》 — 우주 산업시설 건설·경영        |

코메텐베르크는 **기존 준회원 23개 기업 중 하나**다. 회사 수를 새로 늘리지 않으며, 세금 납부·군사적 보호는 있지만 평의회 표결권은 없다. 자유기업연합당의 정식 회원으로 두지 않는다.

금성은 화위안 그룹과 국가 조직이 결합한 체제로 독립 기업 설립·운영을 허용하지 않는다. 별도의 금성 게임사를 두지 않는다.

## 제작과 서비스
게임은 사람이 기획·집필·그림·음악·개발을 담당한다. NPC와 적은 정해진 규칙·스크립트·행동 체계로 작동한다.

행성 간 통신 지연 때문에 빠른 반응을 요구하는 경쟁게임은 가까운 거점의 이용자끼리 즐긴다. 먼 거점 사이에는 비동기 전략게임·기록 경쟁·창작물 공유가 발달하며 큰 대회에는 선수들이 개최지로 직접 이동한다.

## 일상의 게임 문화
퇴근 후 게임, 신작 출시, 공동 게임 공간, 대회 중계, 팬 상품과 캐릭터 장식이 생활에 존재한다. 모든 작품이 에덴 계획이나 정치에 연결되지는 않는다. 대형 동물이 희귀한 사회에서는 동물과 숲이 있는 게임의 자연 풍경이 특별한 환상을 제공한다.
