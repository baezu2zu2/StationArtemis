# 거리 미술 총괄

2541년 에덴 계획 개시 시점의 거리·건축·조명·생활상을 게임 배경 제작에 적용하는 확정 미술 방향이다.

## 공통 시대상
우주 생활은 비상 상황이 아니라 여러 세대의 일상이다. 도시는 오랜 기간 증축하고 고쳐 온 생활공간이며, 첨단 설비 옆에 오래된 점포와 생활용품이 공존한다. 주민은 평상복을 입고, 필요한 작업 구역에서만 보호장비를 착용한다.

| 세력 | 첫인상 | 공간의 소유와 운영 |
|---|---|---|
| 아스테리아 | 사람과 거래가 끊임없이 오가는 입체 도시 | 정부·기업·상인·주민이 공간을 나눔 |
| 화성 | 땅과 하늘이 있는 오래된 생활권 | 시민사회와 대기업의 영향력이 공존 |
| 금성 | 모든 것이 관리되고 배정된 생활공간 | 화위안 그룹과 선씨 가문 |
| 소행성대 | 생산시설 안에 들어앉은 도시 | 기업 영지마다 다른 운영·디자인 |

## 공통 제작 기준
1. **하늘과 천장:** 화성은 열린 하늘, 다른 거점은 관리되는 거주 공간이 기본이다.
2. **간판의 통일성:** 아스테리아는 다양하고 금성은 통일되며 소행성대는 기업 경계마다 달라진다.
3. **설비의 노출:** 금성은 생활권에서 가리고 소행성대는 드러낸다. 아스테리아는 구역별로 섞인다.
4. **거리의 여유:** 계층 차이는 통로 폭·채광·소음·조망·개인 공간에 나타난다.
5. **흑백 식별:** 색을 제거해도 공간 구조와 실루엣으로 세력을 구분한다.

색상은 독립적인 색상 필터보다 건축·조명·표지·생활소품에 분배한다. 거리 미술의 확정은 금성의 구체적인 거주 고도·궤도나 USS 본부의 정확한 행정구역을 새로 지정하는 것이 아니다.
