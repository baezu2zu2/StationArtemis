# 깃발 도감

국가기·연합기·공동기구기와 기업기를 구분한다. 소행성대 연합 전체의 깃발과 5대 기업의 깃발은 별개다. 이번에 제작한 디자인을 게임과 세계관 문서의 시각 기준으로 사용한다. 도입 연도나 제정 절차는 이 도감에서 지정하지 않는다.

## 공통 제작 기준
- 비율 **3:2**, 해상도 **1536 × 1024**, PNG 원본.
- 글자 없이 색과 문양으로 구별한다. 도시의 가로기·시설 표지·인게임 인터페이스에 재사용한다.
- 아래 색상 코드는 향후 재제작을 위한 기준 팔레트다. 생성된 PNG의 픽셀 전체가 해당 색상 코드로만 구성된다는 의미는 아니다.
- USS기는 아스테리아 국기와 구분하고, 기업기는 해당 기업의 영지·시설에서 사용한다.
